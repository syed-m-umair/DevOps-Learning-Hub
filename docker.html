Images

docker pull Beginner

Downloads an image (or a repository's images) from a registry such as Docker Hub, so it can be used to create containers locally.

Syntax

docker pull <image>:<tag>

Example

docker pull node:20-alpine
images registry
docker images Beginner

Lists all images currently stored on your local machine, including their repository, tag, image ID, and size.

Example

docker images
images inspect
docker rmi Intermediate

Removes one or more images from local storage. Use -f to force removal of an image that's still referenced by a stopped container.

Example

docker rmi node:20-alpine
images cleanup

Containers

docker run Beginner

Creates and starts a new container from an image. -d runs it in the background, and -p maps a host port to a container port.

Example

docker run -d -p 8080:80 --name my-app nginx
containers core
docker ps Beginner

Lists running containers. Add -a to include stopped ones too.

Example

docker ps -a
containers inspect
docker stop / start / restart Beginner

Controls a container's lifecycle: gracefully stop a running container, start a stopped one, or restart it in one step.

Example

docker stop my-app docker start my-app docker restart my-app
containers lifecycle
docker exec Intermediate

Runs a command inside an already-running container. Commonly used with -it to open an interactive shell for debugging.

Example

docker exec -it my-app sh
containers debugging
docker logs Beginner

Shows the stdout/stderr output of a container. Add -f to follow the log stream live, similar to tail -f.

Example

docker logs -f my-app
containers debugging
docker rm Intermediate

Removes a stopped container. Use -f to force-remove a running one without stopping it first.

Example

docker rm my-app
containers cleanup

Volumes

docker volume create Intermediate

Creates a named volume that Docker manages for persisting data outside a container's writable layer.

Example

docker volume create app-data
volumes storage
Mount a volume Intermediate

Attaches a named volume to a container using -v, so data written inside the container survives container removal.

Example

docker run -d -v app-data:/var/lib/mysql mysql:8
volumes persistence
docker volume ls / rm Beginner

Lists all volumes on the host, or removes a specific one that's no longer attached to any container.

Example

docker volume ls docker volume rm app-data
volumes cleanup

Networking

docker network create Intermediate

Creates a custom bridge network so containers can discover and talk to each other by service name instead of IP address.

Example

docker network create app-net
networking bridge
Attach a container to a network Intermediate

Runs a container on a specific network using --network, enabling it to reach other containers on that same network by name.

Example

docker run -d --network app-net --name api my-api-image
networking containers
docker network ls / inspect Beginner

Lists all Docker networks, or inspects one to see which containers are connected and their assigned IPs.

Example

docker network ls docker network inspect app-net
networking inspect

Docker Compose

docker compose up Intermediate

Builds (if needed) and starts every service defined in docker-compose.yml. Add -d to run in the background and --build to force a rebuild.

Example

docker compose up -d --build
compose core
docker compose down Beginner

Stops and removes all containers, networks (and optionally volumes with -v) created by docker compose up.

Example

docker compose down -v
compose cleanup
docker compose logs / ps Beginner

Views combined logs across all services, or lists the status of every service defined in the compose file.

Example

docker compose logs -f docker compose ps
compose debugging

Dockerfile & Build

docker build Intermediate

Builds an image from a Dockerfile in the given context. -t tags the resulting image with a name and version.

Example

docker build -t my-app:1.0 .
build core
docker tag Beginner

Creates a new tag that refers to an existing image, commonly used to prepare an image for pushing to a specific registry or version.

Example

docker tag my-app:1.0 username/my-app:1.0
build registry
Multi-stage build snippet Advanced

Uses two build stages to keep the final image small: one stage installs dependencies and builds the app, the other copies only the compiled output.

Dockerfile

FROM node:20-alpine AS build WORKDIR /app COPY . . RUN npm ci && npm run build FROM node:20-alpine WORKDIR /app COPY --from=build /app/dist ./dist CMD ["node", "dist/index.js"]
build best-practice

Registry

docker login Beginner

Authenticates with a registry (Docker Hub by default, or a private one with --username and a server address) so you can push and pull private images.

Example

docker login
registry auth
docker push Intermediate

Uploads a tagged local image to its registry, making it available for others (or your CI/CD pipeline) to pull.

Example

docker push username/my-app:1.0
registry ci-cd

System & Cleanup

docker system prune Intermediate

Removes unused containers, networks, dangling images, and build cache to free up disk space. Add -a to also remove all unused images, not just dangling ones.

Example

docker system prune -a
system cleanup
docker stats Intermediate

Streams live CPU, memory, network, and disk I/O usage for all running containers, useful for spotting a resource-hungry service.

Example

docker stats
system monitoring
docker inspect Advanced

Returns detailed JSON metadata about a container, image, volume, or network — IP address, mounted volumes, env vars, restart policy, and more.

Example

docker inspect my-app
system debugging
